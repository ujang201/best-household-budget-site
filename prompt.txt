Buatkan situs anggaran rumah tangga (household budget site) yang asli dan benar-benar berfungsi, untuk bounty make.fun "best-household-budget-site". Situsnya harus berupa file statis di folder app/ tanpa build step dan tanpa referensi jaringan sama sekali — semua script, CSS, dan gambar harus file lokal. Isinya: Dashboard dengan ringkasan pemasukan vs pengeluaran bulan ini, sisa anggaran, dan grafik batang/donat SVG buatan sendiri; halaman Transaksi untuk tambah/ubah/hapus dan filter per kategori dengan data awal realistis dalam rupiah; halaman Anggaran per kategori dengan progress bar; halaman Tujuan Menabung dengan target dan progres; dan halaman Laporan dengan tips hemat berdasarkan data. Semua kontrol harus benar-benar bekerja dan tersimpan di localStorage, layout responsif untuk desktop 1280px dan ponsel 390px. Sertakan juga main.ts (Node 22, stdlib saja) yang menyalin app/ dan screenshots/ ke /output dan menulis dossier.json via buildDossier dari vendor/makefun-frontend.ts, README dengan badge make.fun, prompt.txt, LICENSE MIT dengan baris SPDX, dan .makefun/owner.json berisi wallet yang diberikan.
